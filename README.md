# 向海而和

郑和下西洋沉浸式三维航海展示。体验从浑天仪展开，进入郑和船队航线；船舶沿路线航行，在国家停留页、船体检视和货物详情之间切换。货物和动物均优先使用项目内的本地三维资源。

## 快速开始

### 直接体验

优先运行便携版，无需安装 Node.js、pnpm 或 Python：

`release/ZhengHe-Immersive-0.1.0-Portable.exe`

首次启动时，Windows 可能显示“未知发布者”提示。程序需要摄像头权限才能使用手势；拒绝权限后，仍可使用鼠标、触摸和键盘操作。

### Android 手机和平板

将下面的 APK 发送到 Android 手机或平板并安装：

`release/ZhengHe-Immersive-0.1.0-Android.apk`

App 固定为横屏沉浸式显示，船体、货物、动物、手势识别和音乐资源均已离线打包。首次启动请选择“允许使用摄像头”；拒绝后仍可以用单指点击、拖动和双指开合操作。安装包约 288 MB，建议预留至少 1 GB 可用空间。

APK 要求 Android 6.0 或更高版本。三维资源较多，实际展示建议使用 Android 10 或更新系统、至少 6 GB 内存的设备。

### 网页体验

双击根目录的 `start.bat`，脚本会启动本地网页并自动打开浏览器。不要直接双击 `index.html`，摄像头和模型资源需要通过本地 HTTP 地址加载。

如果 Windows 提示找不到 PowerShell，跳过网页脚本，直接运行上面的便携版 EXE。

### 源码开发

开发环境需要 Node.js 20.19 或更新版本，以及 pnpm。

```powershell
pnpm install
pnpm run dev
```

构建网页：

```powershell
pnpm run build
```

重新封装 Windows 便携版：

```powershell
pnpm run desktop:portable
```

Android 工程和重新封装步骤见 `mobile/README.md`。

## 体验流程

1. 启动后进入浑天仪。将食指指向“郑和船队”标记并停留，或直接用鼠标单击标记。
2. 浑天仪隐藏，展开航线地图；小船会沿 21 个航线节点自动航行，完整航程约 70 秒。
3. 航行到国家停留点时，自动出现全屏图像和文献介绍。再次张开五指、按 `Esc` 或点击关闭按钮后继续航行。
4. 航行中选中小船，可进入船体检视。船舱中的货物带有透明小点和名称提示。
5. 选中可交互货物后，进入独立的三维详情页，可旋转、缩放并阅读说明。
6. 在详情页点赞或按 `Esc` 返回船体或航线；在船体检视中继续返回，则恢复航行。

## 操作说明

### 手势

| 手势 | 使用场景 | 功能 |
| --- | --- | --- |
| 单食指指向并停留约 0.7 秒 | 浑天仪入口、航行小船、船舱货物 | 光点出现圆形进度，走满后自动选择；手指移开或换到其他目标会取消 |
| 拇指与食指捏合后拖动 | 浑天仪、船体检视、货物详情 | 旋转当前展示模型；捏合本身不再承担选择功能 |
| 双手分别用拇指和食指捏住，并改变捏合点间距 | 浑天仪、船体检视、货物详情 | 两手拉开为放大，收缩为缩小 |
| 张开五指并保持 | 航行中 | 第一次暂停小船，第二次继续航行 |
| 张开五指并保持 | 国家停留页 | 关闭国家介绍并继续航行 |
| 点赞并保持约 1 秒 | 货物详情、船体检视、航行中 | 返回上一层；航行中返回浑天仪 |
| V 字手势并保持 | 浑天仪、船体检视、货物详情 | 恢复当前对象的初始角度和缩放 |

手势光标已经加入平滑降速和防抖。货物的手势命中范围为模型屏幕范围的约 1.8 倍，便于稳定选中。

### 鼠标、触摸与键盘

| 操作 | 功能 |
| --- | --- |
| 单击目标或货物列表项 | 选择目标 / 打开货物详情 |
| 按住并拖动 | 旋转浑天仪、船体或货物 |
| 鼠标滚轮 | 缩放当前展示对象 |
| 双指开合 | 缩放当前展示对象 |
| `Esc` | 关闭国家介绍，或返回上一层 |

### 背景音乐

程序在第一次点击或按键后，循环播放古筝曲《山河安澜》。浑天仪和航行阶段音量约为 9%，货物详情页自动降至约 5%，国家图文页自动降至约 4%；场景切换时音量会平滑变化。左下角的音乐按钮可以随时静音或恢复播放，静音设置会保存在本机。音乐文件已随项目离线保存，风声与海浪声仍保持关闭。

《山河安澜》由苏畅演奏，音频由项目负责人提供，来源与使用说明见 `audio/README.md`。

货物会随航程阶段更新。“当前船舱”面板显示该阶段的清单；其中拥有本地三维资源的条目可展开查看。没有本地模型的条目仍保留在清单中，用于呈现本次航程的货物构成。

### 活体随船条目

阿丹阶段的“活体随船”面板提供以下动物的写实三维详情：狮子、长颈鹿（麒麟）、花福鹿、金钱豹、鸵鸟。动物以独立详情模型展示，不固定摆放在船甲板上。

| 类别 | 可展开条目 |
| --- | --- |
| 中国输出 | 青瓷、青花瓷、锦绮、纻丝、花绢、烧珠 |

## 国家停留页

国家停留页与货物更新是两层并行展示：前者负责全屏图像与《瀛涯胜览》原文、今译，后者负责船舱货物的阶段变化。当前自动停留页共有四处：

| 停留点 | 展示主题 |
| --- | --- |
| 满剌加国 | 河桥市集、花锡互市 |
| 溜山国 | 海岛椰林、索缚造船 |
| 古里国 | 立碑互市、珍货交易 |
| 忽鲁谟厮国 | 海陆商埠、西洋珍宝 |

页面优先呈现文言原文；空间允许时同时呈现现代文翻译。国家停留页关闭后，航程从暂停位置继续。

## 项目结构

| 路径 | 用途 |
| --- | --- |
| `src/main.js` | 三维场景、航线、货物阶段、交互和手势逻辑 |
| `src/history.js` | 货物说明与航线基础数据 |
| `src/country-stops.js` | 国家停留页图片、原文与现代文 |
| `public/models/` | 船体、货物和动物的本地三维资源 |
| `public/mediapipe/` | 离线手势模型与 WASM 资源 |
| `electron/main.cjs` | Windows 便携版的本地服务和摄像头权限控制 |
| `mobile/` | Android 手机和平板 App 工程、权限与签名配置 |
| `release/` | 构建完成的 Windows 便携版与 Android APK |

## 交付说明

Windows 便携版 EXE 和 Android APK 都可以单独发送，接收方不需要项目源码、Node.js、pnpm 或 `dist` 文件。建议通过压缩包或网盘传输，以避免聊天软件拦截安装文件。Android 新版本必须继续使用 `mobile/zhenghe-release.jks` 签名，才能在原 App 上覆盖安装。
