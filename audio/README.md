# Background music

`shanhe-anlan-su-chang.mp3`

- Title: Shanhe Anlan (山河安澜)
- Instrument: Guzheng
- Performer: Su Chang (苏畅)
- Album: 乐典：古筝——苏畅
- Source file: supplied by the project owner

The application plays this local file at low volume and loops it as background music. Volume is reduced further during cargo details and country reading scenes. Public redistribution requires permission from the applicable rights holder.
