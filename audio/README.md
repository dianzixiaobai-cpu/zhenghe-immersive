# Background music

`zuiyu-changwan.ogg`

- Title: Zuiyu Changwan (醉渔唱晚)
- Instrument: Guqin
- Performer: Charlie Huang
- License: CC BY-SA 3.0
- Source: https://commons.wikimedia.org/wiki/File:Guqin-Zuiyu_Changwan.ogg

The application plays this local file at low volume and loops it as background music. Volume is reduced further during cargo details and country reading scenes.
